# 🛒 বাজার দর (Bazar-Dor-Project)

> A modern, real-time web application designed to track and monitor daily essential commodity prices in local markets—keeping consumers informed with up-to-date pricing trends, category breakdowns, and market fluctuations.
[![Live Demo](https://bazar-dor-project-psi.vercel.app/)

---

## 🚀 About The Project

**বাজার দর** is built to address the everyday need for transparent market pricing. Whether it's rice, lentils, cooking oil, vegetables, fish, meat, or spices, the platform aggregates current rates, highlights daily price surges or drops, and organizes everything into a clean, accessible dashboard for everyday shoppers.

---

## 🛠️ Technologies Used

* **Framework:** [Next.js](https://nextjs.org/) (React)
* **Styling & UI:** Tailwind CSS, DaisyUI
* **Icons & Assets:** React Icons
* **Deployment Platform:** [Vercel](https://vercel.com/)
* **Version Control:** Git & GitHub

---

## ✨ Key Features

1. **📊 Real-Time Price Tracking & Trends**  
   Instantly view current market rates alongside clear daily percentage indicators (showing price increases ▲ or decreases ▼) to make smart purchasing decisions.

2. **📂 Categorized Commodity Navigation**  
   Quickly filter and browse products by dedicated categories—including Rice (চাল), Lentils (ডাল), Oil (তেল), Vegetables (সবজি), Fish (মাছ), Meat (মাংস), Dairy (ডিম-দুধ), and Spices (মসলা).

3. **🔍 Comprehensive Product Overview**  
   Access itemized pricing details showing unit-based rates (per kg, litre, dozen, or piece) across a robust catalog of essential household goods.

4. **🔐 User Authentication System**  
   Secure [Sign In](https://bazar-dor-project-psi.vercel.app/signin) and [Sign Up](https://bazar-dor-project-psi.vercel.app/signup) functionality allowing users to create accounts, save preferences, and personalize their market tracking experience.

5. **📱 Fully Responsive Modern UI**  
   Designed with a mobile-first approach using Tailwind CSS and DaisyUI, ensuring a seamless and fast browsing experience across smartphones, tablets, and desktop computers.
